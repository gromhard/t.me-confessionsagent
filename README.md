# 🔒 Бот предложки https://t.me/confessionsagent
# 🚀 Настройка и запуск
1. Откройте файл `.env` и укажите свои данные:
   ```env
   BOT_TOKEN=ваш_токен_бота
   CHANNEL_ID=-100xxxxxxxxxx
   ADMIN_CHAT_IDS=ваш_telegram_id
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите бота:
   ```bash
   python main.py
   ```
